# 管道频散嵌入与新频域数据集最终计划

## 1. 目标与边界

目标是在稀疏 `16x16` 收发条件下直接反演管道剩余厚度，并把频散关系作为网络条件，
而不是只作为损失函数。旧任务和历史数据保持只读：

- `output2/`：历史全频扫描和试验数据；
- `output_dataset/`：旧 top15 数据源；
- `output_dataset_new/`：当前筛选出的 341 个有效样本；
- `new/`：后续频散、校准、网格验证和 v2 数据集代码及模型的唯一目录。

## 2. 已确认问题与技术选择

- 当前长管 Shell 保留曲率和壳弯曲/膜内耦合，可生成与训练数据一致的管道频散先验。
- 现有两圈 FRF 只有一个轴向距离，且只导出轴向位移，不能唯一识别轴向波数。
- 单贴片激励的健康 FRF 包含多个周向阶次，不能只使用一条平板 A0、S0 或轴对称管模态。
- 当前网格按 `60 kHz` 设置，但有效数据包含 `95 kHz`，必须先做网格收敛门禁。
- 主条件采用多模态管道频散曲线；平板 A0/S0 只作理论对照；少量 3D/实测数据校准 Shell 偏差。

## 3. 仿真任务

### 阶段 A：周期 Shell 管道频散库

建立一个均匀短管周期单胞，扫描 `h=5,6,7,8,9,10 mm` 和轴向波数。输出：

```text
k_z, frequency_hz, phase/group_velocity, dk_dh,
circumferential_order, branch_id, polarization,
transducer_observability, tracking_residual
```

先用每个厚度 31 个波数点，分支交叉处自适应加密。频散库一次生成、全部缺陷样本共享。

### 阶段 B：有限长管与网格验证

- 用 `h=5,7.5,10 mm`、一个 TX 和候选频率导出规则 `z-theta` 三分量复位移场。
- 利用健康均匀管旋转对称性验证周向模态，无需重复求解 16 个 TX。
- 在 `20/52.5/95 kHz` 和极端厚度上比较三级网格。
- 要求主分支波数变化小于 2%，有限管场谱与单胞偏差小于 3%。

### 阶段 C：少量 3D 校准

3D 不生成批量缺陷训练集。只建立一个周期实体管单胞，使用 `h=5,7.5,10 mm`，
首轮最多 36 次本征求解；可选典型缺陷不超过 `3 case x 1 TX x 5 frequency`。
输出 Shell-to-3D 波数修正和置信度，计算预算不得超过 Shell 训练集的 10%。

### 阶段 D：选频与 200 样本 v2 数据集

- 综合厚度灵敏度、模态可观测性、校准置信度和旧 physics score，优先选择 10 个频点；
- 信息损失明显时扩展到 12 个，不再为每个样本运行 33 频点全扫；
- 新数据写入 `new/outputs/dataset_v2/`，旧数据不覆盖；
- 首批生成 200 个平衡缺陷样本，通过确定性基线后再考虑扩展到 400-600 个。

预算公式：

```text
wall_hours = 4 h * sample_count * frequency_count / 15
             * mesh_time_ratio / effective_workers * 1.15
```

## 4. 频散如何进入 EDM

1. 按样本真实 `frequency_hz` 插值管道频散库，并保持频率轴与 `x_matrix` 同序。
2. 用 `phase_cos/phase_sin` 与候选厚度、模态、有效作用长度模板匹配，形成路径厚度后验。
3. 将路径后验、熵、残差和置信度反投影为空间证据图，通过 PicAdapter 多尺度注入。
4. 将 `k_z/c_g/dk_dh/模态权重/校准置信度` 编成 frequency/TX-RX token，进入现有 FiLM 和 cross-attention。
5. 幅值与原始复频响保留学习残差支路，吸收阻尼、散射、多模态混合和仿真到实测偏差。
6. 物理损失仅作可选辅助；主要物理信息已通过 token 和空间图进入网络。

频散分支新增参数控制在 0.5M 以内。200 样本阶段先使用较小确定性 U-Net 和 base32 EDM，
现有约 18.45M 参数的 base48 模型留到数据扩展后使用。

## 5. 阶段门禁与完成标准

- 本机只做模型树、单工况、导出格式和张量 smoke test；正式计时以服务器基准为准。
- 周期库厚度留一插值误差小于 2%，模态分支连续且单位/元数据完整。
- Shell 与 3D 偏差超过 5% 的模态降低置信度，不作为强物理条件。
- 10 频点相对 15 频点的确定性基线下降超出验证波动时改用 12 频点。
- 200 样本按缺陷数量、尺寸、深度分层为 `160/20/20`，只用独立 test 决定是否扩容。
- 消融至少包括：原条件、频散 token、频散 token 加空间证据图。
- 正式 EDM 仍需完整 held-out 评估、K=16/32 后验采样和毫米尺度物理指标。

实施必须遵守每次提交不超过 200 行、5 个文件；每个阶段验证通过后独立提交。
