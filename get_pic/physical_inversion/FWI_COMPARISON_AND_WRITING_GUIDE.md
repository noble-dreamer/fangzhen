# 当前复 Rytov 射线层析、FWI 与 EDM 的比较和写作边界

## 结论先行

当前 `physical_inversion` 的正式方法不是 Full-Waveform Inversion（FWI）。它是一个**由独立
COMSOL 语料标定的复 Rytov 路径层析基线**：先把每条 TX-RX 路径的多频复响应压缩为一个毫米路径
观测，再用固定螺旋射线核做非负 SIRT 与 TV 重建。

基于现有的频域数据，可以实现**频域 FWI**，不需要时域波形；但它不能由当前脚本直接得到。真正的
FWI 需要一个随壁厚场更新的全波 COMSOL 前向模型及其梯度/伴随实现。直接把目前的 64x64 图像网格
作为 4096 个自由参数进行 COMSOL 有限差分优化，计算量不现实。实际可行的第一步是低维、低频到
高频续进的频域 FWI 原型；在没有完成这一项之前，论文不能把当前基线称为 FWI，也不应宣称 EDM
优于 FWI。

即使暂不做 FWI，论文仍可以成立：将比较问题明确限定为“在稀疏多频复传递响应下，学习型先验是否
比仿真标定的线性化射线层析更能恢复多缺陷形态”。这是一条清楚、可验证且公平的研究主线。

## 当前可用数据与方法

正式数据位于：

```text
simple/f_domain/output_dataset/streaming_dataset_a_frequency_shell/
```

每个样本和冻结健康基线都包含复数接收响应：

```text
H[tx, rx, f] = H_real + i H_imag
shape        = (16, 16, 15)
measurement  = 3840 个复数，或 7680 个实数自由度
```

15 个频点按敏感度排名保存而不是升序；用于 FWI 频率续进时应在内存中按 Hz 升序排列，而不能改变
样本内 `H` 的对应关系。最小可用频率为 20 kHz，随后有 32.5、40、42.5 kHz 等频点。缺少更低频率
会降低 FWI 避免 cycle skipping 的能力，但不使频域 FWI 在理论上失效。

当前 v2 反演的计算链为：

```text
H0, Hd[16,16,15]
       |
       | regularized complex Rytov + 仿真标定的 offset/frequency 通道模型
       v
u_hat[path] [256 个毫米路径观测]
       |
       | K_fixed[256,4096] + nonnegative SIRT + periodic TV
       v
d_hat[64,64] -> resize -> prediction_mm[256,256]
```

其中：

```text
K_fixed(path, r) = sum_o alpha_o K_o(path, r),  o in {-1, 0, +1}
alpha            = [0.35, 0.30, 0.35]
```

通道标定完全来自 48 个独立 COMSOL 缺陷样本，正式 40 个样本的标签不参与反演。该基线的优点是
毫米尺度清楚、推理快、不会把正式标签泄漏到反演中；它的限制是全波散射信息在进入 SIRT 前已被压缩。

## 为什么当前方法不是 FWI

| 项目                     | 当前复 Rytov 射线层析                             | 频域 FWI                                         |
| ------------------------ | ------------------------------------------------- | ------------------------------------------------ |
| 被拟合的数据             | 由`H0,Hd` 提取并融合后的 256 个 `u_hat[path]` | 原始复数据`Hobs(tx,rx,f)`                      |
| 前向模型                 | 固定几何射线矩阵`K_fixed`                       | 随当前壁厚场改变的弹性/壳体波动方程              |
| 模型与数据关系           | 线性近似：`u_hat ~= K_fixed d`                  | 非线性：`Hobs ~= P A(m,f)^(-1) q`              |
| 每次迭代是否重算波场     | 否                                                | 是，且需前向与伴随波场                           |
| 梯度                     | SIRT 的`K_fixed.T residual`                     | 波动方程伴随梯度`dH/dm`                        |
| 多重散射、模态转换、干涉 | 未显式建模                                        | 由全波方程建模，前提是模型足够准确               |
| 主要风险                 | 欠定、路径覆盖不足、固定核失配                    | cycle skipping、模型失配、局部极小、极高计算代价 |

对频率 `f`、发射源 `s` 和壁厚/减薄模型 `m`，FWI 的形式是：

```text
A_f(m) u_s,f = q_s,f
Hpred_s,f(m) = P u_s,f

Phi(m) = sum_s,f || W_s,f [Hobs_s,f - Hpred_s,f(m)] ||_2^2
         + lambda_TV TV(m) + lambda_prior R(m)
```

伴随方法通过当前残差构造伴随源，得到 `nabla_m Phi` 后更新 `m`。因此 FWI 的关键不是“也使用了复数
频响”或“也使用 COMSOL”，而是**每次模型更新后重新求解全波场，并按波形残差更新模型**。当前方法
没有这一循环，所以准确名称应为：

```text
simulation-calibrated complex-Rytov helical ray tomography
```

## 图像中的多缺陷不稳定性如何解释

示例 `dataset_a_frequency_sample_0011` 的真值有两个缺陷。当前图像能在主缺陷附近形成响应，但小缺陷
未稳定分离，同时出现边界亮带和块状扩散。这与方法假设一致，不宜解释为单个 TV 参数选择失误。

1. **多频复数据被压缩。** 每条路径原本有 15 个复观测，最终只保留一个融合后的标量 `u_hat[path]`。
   多频相位、模态干涉和散射形状差异无法在图像求解阶段继续区分。
2. **路径量不能唯一分配给多个位置。** 同一路径同时穿过或接近多个缺陷时，实际 `Hd-H0` 包含相干
   叠加和多重散射。当前模型将它解释为单一线性路径平均值 `K_fixed d`，没有足够信息将总异常可靠地
   分配到两个独立像素区域。
3. **`K_fixed` 是全局、频率无关的几何混合核。** 三个螺旋阶次使用同一组全局 `alpha`；实际导波贡献
   会随频率、路径长度、模式与散射位置改变，也可能发生相位相消。
4. **原问题本身欠定。** 成像变量在 64x64 网格上有 4096 个，射线观测只有 256 个；而 256 条路径
   也不是独立均匀覆盖。输出到 256x256 只是插值，不能增加物理分辨率。
5. **正则化带来可预期偏差。** 非负约束、TV 与有限 support 会倾向于把相邻异常合并成平滑块，并将
   不可解释的路径残差投影到高覆盖区域或边界附近；峰值也会被空间平均而降低。

对当前 40 例输出按标签中的缺陷数量做的描述性分组如下。它不是独立显著性检验，但支持将“多缺陷
条件下的空间分配和假阳性”作为重点分析，而不是只报告总平均分数：

| 真值缺陷数 |  n | Pearson |  Dice | RMSE (mm) | 假阳性均值 (mm) | 峰值位置误差 (mm) |
| ---------: | -: | ------: | ----: | --------: | --------------: | ----------------: |
|          1 |  9 |   0.560 | 0.280 |     0.280 |           0.070 |              80.8 |
|          2 | 22 |   0.550 | 0.290 |     0.340 |           0.080 |             236.5 |
|          3 |  9 |   0.600 | 0.300 |     0.390 |           0.090 |             228.9 |

例如 sample 0011 的 Dice 为 `0.332`、RMSE 为 `0.452 mm`，预测峰值 `3.526 mm` 小于真值峰值
`4.301 mm`。它说明主异常有一定定位信息，但不能证明两个缺陷都被可靠恢复。上述分组样本量较小，
写作时应报告 bootstrap 置信区间或至少展示全部样本散点，避免将该趋势写成未经检验的普遍定律。

## 能否做 FWI

可以做频域 FWI，但需要新建独立的反演路径。现有数据已经满足三个必要条件：

1. 每个 TX-RX-频率都有完整复响应，而不是只有幅值图；
2. 有冻结健康基线 `H0`、已知管道几何、材料、激励和接收器定义；
3. COMSOL 前向模型本身已经是频域壳体模型，接收量也是明确的 patch-weighted 轴向位移。

当前缺失的是 FWI 真正需要的部分：

1. **连续壁厚场参数化。** 现有 COMSOL 缺陷生成器主要构造有限个显式缺陷。FWI 需要让
   `d(theta,z)` 或等效壳厚场成为可优化变量，并在更新后稳定地影响壳体厚度、刚度和质量。
2. **波形 Jacobian 或伴随梯度。** 目前没有 `dH/dm`，也没有将接收残差回注为伴随源的代码。
   COMSOL 的优化/灵敏度能力、LiveLink API 和许可证是否可用必须先验证；不能假设现有 `mph` 导出
   脚本自动具备伴随能力。
3. **稳定的复数失配。** 应以归一化复残差或鲁棒的对数幅值加相位残差拟合；不能直接沿用当前
   “response-to-path-mm”的标定。
4. **多尺度初始化与正则化。** 必须按频率由低到高推进，并对厚度施加范围、TV 或 B-spline 先验。
   仅从零缺陷背景直接加入高频，很容易发生 phase/cycle skipping。
5. **计算预算与验证设计。** 一次全数据迭代至少约为 16 x 15 = 240 个前向源-频率求解；若每个
   残差可合成为一个接收环的伴随源，还需要约 240 个伴随求解。没有伴随梯度时，`N` 个参数的有限
   差分大约需要 `240 x (N+1)` 个求解/迭代，不能用于 4096 像素。

“3840 个复观测多于 4096 个像素的一半”不等价于高分辨率可辨识。接收通道和频点之间相关性很强，
有效秩受导波模态、有限孔径、噪声、模型误差和频率带宽共同限制。

## 推荐的 FWI 实施层级

### 层级 A：先验证波形闭合，不称为 FWI

在任何迭代之前，使用当前健康 COMSOL 模型重新计算 `H0`，并验证同一 TX、RX、频率、激励幅值、
接收 patch 积分和复数相位约定。若健康复响应无法复现，FWI 的残差主要会拟合模型误差，后续结果
没有可解释性。

随后选一个独立合成缺陷，验证从真实模型 `m_true` 生成的 `Hobs` 可被健康模型到正确模型的前向计算
连续追踪。这是最基本的 synthetic recovery test，也可暴露频率顺序、符号和接收算子不一致。

### 层级 B：低维频域 FWI 原型，推荐的首个可发表对照

将厚度场限制为低维 B-spline、少量径向基函数或 level-set 参数，而不是直接优化 64x64 像素：

```text
有伴随梯度： 8x16 或更低分辨率的系数场，可逐步增加分辨率
无伴随梯度： 10-30 个形状/基函数参数，只用于概念验证
```

使用同一 `H[16,16,15]`，按频率排序做 continuation，例如先使用低频子集，再逐步加入中高频。每阶段
使用复数归一化残差、壁厚边界和 TV/系数平滑正则化。没有伴随梯度的版本应明确命名为
“reduced-order finite-difference waveform fitting”，不能写成高分辨率 FWI。

### 层级 C：全场频域 FWI，只有在伴随梯度可用时才建议

建立连续壳厚参数场、稳定更新网格或等效壳物性场，并实现/调用伴随梯度。优化可以采用 L-BFGS 或
Gauss-Newton 型步骤，配合 source batching、频率 continuation、TV 与物理厚度约束。此时才可将
方法称为 frequency-domain guided-wave FWI。

全场 FWI 仍不保证多缺陷优于 EDM：如果实际模式、阻尼、激励、边界、材料或接收器模型与数据不一致，
它可能把系统误差吸收到壁厚图中。FWI 的价值是提供完整波形数据一致性的物理上限/下限，而不是自动
得到视觉上最好的图。

## 比完整 FWI 更实际的中间基线

若目标是先得到一个比固定射线核更强、但计算可控的物理对照，优先考虑**全波线性化 Born/Rytov
反演**，而不是把它称为 FWI：

```text
delta h = log(Hd / H0) ~= J delta d
min_d || W^(1/2)(delta h - J d) ||_2^2 + lambda_TV TV(d)
```

这里的 `J` 必须是由 COMSOL/伴随或受控有限差分得到的复数全波灵敏度核，而不是当前的几何射线管。
它仍只在健康背景附近线性化，因此不是 FWI；但它保留频率、路径和复相位的空间敏感度，比先压缩成
256 个路径深度更接近全波数据。若只能获得低秩或低维 `J`，应明确报告其参数化和分辨率上限。

## 与 EDM 的公平比较协议

| 方法                            | 推理时输入                    | 是否使用正式标签                   | 是否更新全波模型   | 应报告的数据一致性                     |
| ------------------------------- | ----------------------------- | ---------------------------------- | ------------------ | -------------------------------------- |
| 当前复 Rytov 射线层析           | `H0,Hd`，再压缩为 `u_hat` | 否                                 | 否                 | `                                      |
| Born/Rytov 全波线性化（若实现） | 原始复`H0,Hd`               | 否                                 | 否，围绕健康线性化 | 复数线性化残差                         |
| FWI（若实现）                   | 原始复`Hobs`                | 否                                 | 是                 | 归一化复波形残差                       |
| EDM                             | `x_matrix` 与 `pic(x)`    | 训练阶段使用训练集标签；推理阶段否 | 否                 | 标签指标；可在代表性样本补充前向复残差 |

公平性规则：

1. 所有方法使用同一批正式 `H0/Hd`、相同坐标、相同毫米色标和同一测试划分；
2. 物理方法的 `alpha`、通道模型、FWI 正则化权重和停止准则不得使用评价样本标签选择；
3. EDM 的训练、验证和最终测试划分必须冻结。EDM 若使用标签学习形态先验，其优势应表述为
   “learned prior 的优势”，而不是无条件宣称更好的纯物理反演器；
4. 除 MAE/RMSE 外，至少报告 Dice/IoU、峰值深度比、峰值位置误差、假阳性能量、缺陷数分层结果；
5. 若实现 FWI，对每个方法都尽可能报告由其输出重新正演得到的复数据残差。只比较图像与标签会掩盖
   EDM 的潜在数据不一致性，也会掩盖 FWI 的物理数据拟合优势；
6. 对多缺陷样本单独报告统计分布、代表性成功/失败案例和不确定性，而不是只给全体平均图。

## 不做 FWI 时的论文写作逻辑

可采用下面的论证链：

```text
问题：从稀疏、多频、复导波传递响应恢复管壁减薄图。
挑战：有限环阵孔径、模式混合、相位干涉与多缺陷共同使问题高度欠定。
物理基线：使用独立 COMSOL 语料标定的复 Rytov 螺旋射线层析；它提供无正式标签泄漏的毫米基线。
观察：该线性化基线能定位部分主异常，但在多缺陷、边界和峰值恢复上受固定核与路径压缩限制。
学习方法：EDM 从训练分布学习形态先验，并融合原始频域条件与粗物理图像。
结论边界：EDM 优于本研究的仿真标定射线层析基线；这证明学习先验在该稀疏测量设置中的价值，
          不等价于宣称 EDM 已优于完整 FWI。
```

建议的方法命名与避免的表述：

| 可以使用                           | 不应使用                   |
| ---------------------------------- | -------------------------- |
| 仿真标定复 Rytov 螺旋射线层析      | 当前方法是 FWI             |
| 固定核、线性化物理基线             | 当前方法保留了完整全波信息 |
| 学习型后验/形态先验改善稀疏反演    | EDM 在所有情况下优于 FWI   |
| 多缺陷下存在路径分配与模型失配限制 | 低 Dice 仅由 TV 参数造成   |

可直接写入论文的方法定位段落：

> We use a simulation-calibrated complex-Rytov helical ray tomography method as a
> label-free physics baseline. It maps multi-frequency complex transfer responses to
> path-integrated wall-loss estimates and reconstructs a bounded thickness-loss map
> with a fixed helical operator and TV regularization. This baseline is deliberately
> distinguished from full-waveform inversion: it does not update a wave-equation
> forward model using waveform residuals. The comparison therefore evaluates whether
> the learned diffusion prior improves recovery under sparse guided-wave measurements
> relative to a calibrated linearized physics inversion, rather than claiming a
> comparison against a full FWI optimum.

## 推荐的图表与结果组织

1. **方法图：** `H -> current path compression -> K_fixed/SIRT-TV` 与
   `H -> wave-equation forward/adjoint -> FWI update` 并列，EDM 作为条件后验分支；
2. **代表案例：** 单缺陷、双缺陷、三缺陷各至少一例，统一展示 prediction、truth、absolute error；
3. **分层统计：** 按缺陷数、深度、面积、边界距离和频率响应强度分组，报告中位数与区间；
4. **数据空间与图像空间：** 若有 FWI/Born，画复数据残差与 Dice/RMSE 的散点，说明“拟合波形”不总是
   等于“恢复形态”；
5. **EDM 不确定性：** 多次采样给出均值、方差或置信图，重点观察小缺陷和边界假阳性；
6. **消融：** EDM 仅 `x_matrix`、仅 `pic(x)`、二者融合；物理基线的幅值/相位融合与固定核设置。

在没有完整 FWI 时，最强的写法不是回避它，而是明确其所需的可微全波模型、计算规模和模型失配风险，
并将它列为后续工作。这样当前比较的范围、物理基线的价值和 EDM 的真实贡献都保持可审查。
